# Travel Wallet Bot

Telegram-бот для управления бюджетом в путешествии. Пользователь создаёт поездку, указывает страну отправления и назначения, получает курс валют и ведёт учёт расходов в двух валютах одновременно. Данные сохраняются в локальной базе SQLite.

## Возможности

- пошаговое создание путешествия: страна отправления → страна назначения → начальная сумма;
- автоматическое определение валюты по названию страны (справочник 60+ стран);
- получение актуального курса через внешнее API;
- хранение баланса в домашней валюте и в валюте путешествия;
- запись расходов с описанием;
- просмотр истории транзакций;
- ручное изменение курса обмена;
- работа с несколькими путешествиями и переключение активной поездки.

## Технологии

- Python 3.12
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) — Telegram Bot API
- SQLite (`sqlite3`, стандартная библиотека)
- [requests](https://requests.readthedocs.io/) — HTTP-запросы к API курсов валют
- [python-dotenv](https://github.com/theskumar/python-dotenv) — загрузка переменных окружения

## Установка

```bash
git clone https://github.com/lotusrussia-commits/currency-travel-bot.git
cd currency-travel-bot
```

Создание виртуального окружения:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Настройка `.env`:

```bash
cp .env.example .env
```

В файле `.env` необходимо указать:

| Переменная  | Обязательная | Описание |
|-------------|--------------|----------|
| `BOT_TOKEN` | да           | токен Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `DB_PATH`   | нет          | путь к файлу SQLite (по умолчанию: `travel_wallet.db`) |

## Запуск

```bash
source venv/bin/activate
python travel_wallet_bot.py
```

Или через скрипт:

```bash
chmod +x run.sh
./run.sh
```

Также можно запустить без ручной активации venv — скрипт автоматически переключится на `venv/bin/python3`, если окружение уже создано:

```bash
python3 travel_wallet_bot.py
```

## Использование

1. Отправьте боту `/start` — появится главное меню.
2. **🌍 Создать путешествие** — введите страну отправления (например, `Россия`), страну назначения (`Китай`) и начальную сумму (`150000`).
3. **💰 Баланс** — просмотр остатка в обеих валютах; кнопка **➖ Записать расход** для добавления траты.
4. **📊 История расходов** — последние 20 транзакций активной поездки.
5. **⚙ Изменить курс** — ручная установка курса обмена.
6. **🧳 Мои путешествия** — список поездок; отправьте ID, чтобы сделать поездку активной.

Дополнительные команды:

- `/help` — справка по возможностям бота;
- `/cancel` — отмена текущего диалога.

## Обработка данных

При первом запуске создаётся файл SQLite (по умолчанию `travel_wallet.db`) со следующими таблицами:

| Таблица | Назначение |
|---------|------------|
| `users` | пользователи Telegram и активное путешествие |
| `trips` | поездки, балансы, курс обмена |
| `transactions` | история расходов и начального баланса |
| `countries_currencies` | справочник стран и валют |

## Обработка ошибок

- если `BOT_TOKEN` не задан — бот завершит работу с сообщением в лог;
- если страна не найдена в справочнике — пользователь получит подсказку и сможет ввести название заново;
- если API курсов валют недоступно — создание путешествия прерывается без падения программы; курс можно задать вручную через **⚙ Изменить курс**;
- некорректный ввод суммы или курса — бот просит повторить ввод;
- ошибки HTTP-запросов к API логируются и возвращаются пользователю в понятном виде.
