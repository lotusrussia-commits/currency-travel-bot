# Travel Wallet Bot

Telegram-бот для управления бюджетом в путешествии. Позволяет создавать поездки, отслеживать баланс в двух валютах одновременно, записывать расходы и просматривать историю транзакций.

## Возможности

- **Создание путешествия** — пошаговый диалог: страна отправления → страна назначения → начальная сумма
- **Автоопределение валюты** по названию страны (справочник 60+ стран)
- **Актуальный курс** через внешнее API с graceful degradation при недоступности
- **Двойной баланс** — одновременно в домашней валюте и валюте путешествия
- **История расходов** — все транзакции сохраняются в SQLite
- **Ручное изменение курса** — если API недоступно или нужен свой курс
- **Несколько путешествий** — переключение между поездками

## Требования

- Python 3.12+
- Telegram Bot Token ([@BotFather](https://t.me/BotFather))

## Установка

```bash
# Клонировать репозиторий и перейти в директорию
cd currency-travel-bot-v2

# Создать виртуальное окружение
python3.12 -m venv venv
source venv/bin/activate   # Linux/macOS
# venv\Scripts\activate    # Windows

# Установить зависимости
pip install -r requirements.txt

# Настроить переменные окружения
cp .env.example .env
# Отредактировать .env — указать BOT_TOKEN
```

## Запуск

```bash
python travel_wallet_bot.py
```

## Переменные окружения

| Переменная   | Обязательная | Описание                          |
|-------------|--------------|-----------------------------------|
| `BOT_TOKEN` | Да           | Токен Telegram-бота               |
| `DB_PATH`   | Нет          | Путь к SQLite (default: `travel_wallet.db`) |

## Использование

1. Отправьте `/start` — появится главное меню.
2. **Создать путешествие** — введите страну отправления (например, `Россия`), затем назначения (`Китай`) и начальную сумму (`150000`).
3. **Баланс** — просмотр остатка в обеих валютах и запись расходов.
4. **История расходов** — последние 20 транзакций.
5. **Изменить курс** — задать курс вручную.
6. **Мои путешествия** — список поездок; отправьте ID для активации.

## База данных

При первом запуске автоматически создаются таблицы:

| Таблица               | Назначение                              |
|-----------------------|-----------------------------------------|
| `users`               | Пользователи и активное путешествие     |
| `trips`               | Путешествия с балансами и курсом        |
| `transactions`        | История расходов и пополнений           |
| `countries_currencies`| Справочник стран и валют (60+ записей)  |

## API курсов валют

Все запросы к внешнему API выполняются **только** через `current_api.py` (open.er-api.com, без API-ключа).

При недоступности сервиса бот не падает — пользователь получает понятное сообщение с предложением задать курс вручную.
